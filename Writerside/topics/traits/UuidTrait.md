# UuidTrait

<secondary-label ref="1.1" />

Use this trait to add an ID based on <tooltip term="UUID">UUID</tooltip> that is randomly generated.

## Glossary

`getId()`
: Get ID of Entity.
: **Return** `Symfony\Component\Uid\Uuid` or `null`

`setId()`
: Set ID of Entity.
: **Param** `$id` can be `Symfony\Component\Uid\Uuid` or `null`
: **Return** `EntityObject`
