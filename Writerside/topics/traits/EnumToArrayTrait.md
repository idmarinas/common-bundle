# EnumToArrayTrait

<secondary-label ref="3.5" />

This trait add static methods to Enum class to get `names`, `values` or `asArray`

## Glossary

`names()`
: Get names of enum
: **Return** `array`

`values()`
: Get values of enum
: **Return** `array`

`asArray()`
: Get an associative array `name => value`
: **Return** `array<string, string>`
