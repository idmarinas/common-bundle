# FakerTrait

<secondary-label ref="1.5" />
<secondary-label ref="experimental" />

This trait adds functions to be able to use FakerPHP in your project (mainly in DEV)

## Glossary

`faker()`
: Get a instance of Faker
: **Return** `Faker\Generator`

`populateEntity()`
: Populate an Entity Object with Fake Data
: **Param** `$entity` an entity `object`
: **Return** the entity `object` with Fake Data
