# IdTrait

<secondary-label ref="1.0" />

Use this trait in your entities to add an auto-incremented numeric ID.

## Glossary

`getId()`
: Get ID of Entity.
: **Return** `int` or `null`

`setId()`
: Set ID of Entity.
: **Param** `$id` can be `int` or `null`
: **Return** `EntityObject`
