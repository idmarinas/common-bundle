---

## Usage

```bash
php bin/console idm:generate:crypto:value
```

## Options

You can modify this command with the following options:

::field-group
  ::field{name="--show" type="boolean"}
  Default to `false` - Only display the value without updating the `.env` file.
  ::

  ::field{name="--var" type="string"}
    :::docs-field{since="3.4"}
    Default to `APP_SECRET` - Name of the variable to replace in the `.env` file.
    :::
  ::

  ::field{name="-l, --length" type="int"}
    :::docs-field{since="3.4"}
    Default to `16` - The length of the cryptography key to be generated
    :::
  ::
::
